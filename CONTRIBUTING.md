# Contributing

Pathwise is currently a **solo, early-stage concept project**. There's no
application code yet — this repository holds the product concept, pitch
deck summary, and roadmap docs described in the README.

There's no formal contribution process at this stage:

- Issues and discussion are welcome, but there's no guaranteed response time.
- Pull requests aren't being actively reviewed or accepted yet, since the
  product direction and even the underlying data sources/providers are still
  being validated (see `docs/roadmap.md`).
- This will be updated with real contribution guidelines once the project
  moves past the docs-only stage and an initial codebase exists.

If you're interested in Pathwise, the best starting points are
`docs/concept.md` and `docs/deck-summary.md`.
